# معمارية Tarboo Bot AI Studio

AI Studio طبقة منظمة فوق Auto AI، وليست مزود دردشة بديل. تدخل أولاً لفهم الطلبات العملية، ثم تعيد `false` إلى Auto AI كي يجيب Gemini طبيعياً إذا لم تتطابق أي قدرة منظمة.

## الوحدات الأساسية

| الوحدة | المسؤولية | حالة التعديل |
|---|---|---|
| `maro-ai-studio.js` | يكتشف النية، يقرأ المرفق المسموح، وينشئ خطط البلوقنات والوسائط. | أساس التنفيذ الجديد. |
| `maro-code-review.js` | يجد ملفات المشروع ويحللها ويطبق تعديلات مقترحة بعد موافقة المالك. | يعاد استخدامه للمراجعة الداخلية. |
| `maro-natural-ai.js` | أوامر صحة البوت والذاكرة والمنشن وصورة الملف. | يعالج الطلبات التشغيلية السريعة أولاً. |
| `maro-builder.js` | يبني الأزرار والبطاقات والقوائم ورسائل Meta الغنية. | يعاد استخدامه، ولا يعاد اختراعه. |
| `maro-plugins.js` | عقد البلوقنات والتحميل وإعادة التحميل. | مصدر الحقيقة لأسماء الأوامر والفئات. |

## سجل النوايا

| النية | مثال طبيعي | النتيجة |
|---|---|---|
| تحليل مرفق | «حلل هذا البلوقن» مع الرد على ملف | تقرير عربي عن العقد والأوامر والمخاطر والاعتماديات. |
| تكييف بلوقن | «عدله ليناسب بوتي وضعه في AI» | خطة فرق وملف مقترح فقط، ثم موافقة المالك قبل الكتابة. |
| إنشاء بلوقن | «أنشئ بلوقن يحول MP3 إلى رسالة صوتية» | مسودة بلوقن عربي قابلة للتنزيل ثم موافقة منفصلة للتثبيت. |
| إنشاء صورة | «أنشئ صورة …» | تمرير الوصف إلى موفر صورة محدود، ثم إرسال الناتج في المحادثة. |
| تعديل صورة | «عدّل هذه الصورة …» مع الرد على صورة | يطلب موافقة المالك قبل رفع الصورة إلى موفر خارجي ثم يرسل الناتج. |
| إخراج منظم | «أرسله كملف» أو «أرسله كنص» | يختار المستند أو النص وفق الحجم ونوع الناتج. |

## دورة إنشاء أو تكييف بلوقن

```text
طلب المالك → استخراج وصف أو ملف مرفق → تحليل ثابت بلا تشغيل → مسودة كود
→ فحص الصياغة والعقد → معاينة تفاصيل الخطة → موافقة صريحة
→ نسخة احتياطية → كتابة داخل plugins/<category>/ → فحص → إعادة تحميل اختيارية
```

لا يسمح AI Studio بتغيير `config.js` أو ملفات الجلسات أو قواعد البيانات أو ملفات الإقلاع عبر هذه الدورة. تبقى هذه الملفات خارج نطاق التعديل التلقائي.

# تقرير التحديث المتقدم لـ Tarboo Bot

## النتيجة

تم تحديث مشروع **Tarboo Bot** ليشمل مسار مراجعة برمجية متقدم يعمل للمطور فقط، ويحلل الملف عبر عدة مزودين موجودين بالفعل داخل المشروع، مع إضافة محلل Manus اختياري يعتمد على مفتاح بيئة مستقل. وأضيفت طبقة نوايا طبيعية لإدارة طلبات مثل صورة الملف الشخصي، والمنشن الانتقائي، وفحص الصحة والذاكرة والملفات من دون كتابة مسارات كاملة. كما تم تفعيل متابعة قناة المالك من الإعدادات الحالية، وتوحيد بيانات القناة في رسائل نظام Case.

## مسار التحليل والتعديل

| المرحلة | السلوك |
|---|---|
| طلب التحليل | يذكر المالك البوت أو يرد على رسالته ثم يكتب `حلل ملف: src/handler.js` |
| التحليل | تُرسل نسخة محدودة من الملف إلى Gemini وClaude Haiku وGPT وDeepSeek، ويُضاف Manus عند توفر `MANUS_API_KEY`، للحصول على تقارير مستقلة |
| التوحيد | يجمع Gemini التقارير في ملخص ومشكلات ومقترحات تعديلات صغيرة قابلة للتحقق |
| الموافقة | يعرض البوت الخطة ثم ينتظر `نعم` أو `موافق` أو `نفذ` من المالك |
| النسخ الاحتياطي | يحفظ نسخة أصلية في `backup/ai-review/` قبل التغيير |
| التحقق | يفحص صياغة JavaScript والاستيرادات المحلية قبل استبدال الملف الأصلي |
| النتيجة | عند الفشل لا يغير الملف الأصلي، وعند النجاح يعرض مسار النسخة الاحتياطية |

## الحماية المقصودة

لا تعمل هذه الميزة إلا للمالك، ولا تُحلل ملفات الإعدادات والأسرار والجلسات وقواعد البيانات. كما أنها لا تنفذ أوامر نظام ولا تتبع تعليمات يقرأها داخل الملف محل التحليل. بقيت أوامر المالك المباشرة الموجودة في البوت كما هي، ولم تُضف لها مصادقة ثنائية بناءً على تفضيلك.

## تحديثات إضافية منفذة

| الملف | التحديث |
|---|---|
| `config.js` | إضافة `saluran.autoFollow: true` لمتابعة قناة المالك المحددة في `saluran.id` |
| `index.js` | متابعة القناة مرة واحدة بعد الاتصال، مع حفظ حالة المتابعة وإزالة استدعاء `startOrderPoller` غير المعرّف |
| `case/maro.js` | استخدام `config.saluran` بدلاً من معرّف قناة ثابت في رسائل القوائم |
| `src/lib/maro-auto-ai.js` | دمج تدفق مراجعة الملفات، وتحسين الذاكرة المحدودة، وهوية Tarboo Bot، وتقرير `LEARNSTATS` للمالك |
| `src/lib/maro-natural-ai.js` | طبقة طلبات طبيعية لصور الملف والمنشن الانتقائي وبحث الملفات وتحليل الصحة والذاكرة وفحص الصياغة للمالك |
| `src/lib/maro-code-review.js` | وحدة التحليل متعدد النماذج، الموافقة، النسخ الاحتياطي، والتحقق، مع بحث ذكي عن الملف المطلوب وDeepSeek كمحلل إضافي |
| `src/scraper/claudehaiku.js` و`src/scraper/qwen3.js` | تحسين قراءة استجابات البث عند الطلب غير المتدفق، ما أعاد تشغيل Claude في الاختبار الحي |
| `src/lib/maro-nvidia-ai.js` وبلوقنات NVIDIA | إزالة المفاتيح المضمّنة، واستخدام `NVIDIA_API_KEY` أو `NVIDIA_API_KEYS` من بيئة السيرفر فقط |
| `src/scraper/manus-agent.js` | مزود Manus اختياري لمراجعة الكود؛ ينشئ مهمة خاصة غير تفاعلية، ينتظر تقريراً محدوداً، ويتوقف بأمان عند حالة انتظار أو خطأ |
| `tests/manus-agent.test.mjs` | اختبار محاكى لإنشاء المهمة، انتظار التقرير، وعدم تعطل البوت عند غياب المفتاح |
| `MANUS_PROVIDER_SETUP.md` | دليل تفعيل `MANUS_API_KEY` من بيئة الاستضافة من دون تخزينه داخل الكود |
| `AUTO_AI_NATURAL_CONTROL_GUIDE.md` | دليل أوامر اللغة الطبيعية وحدودها ونتيجة تقييم مزودات AI |
| `NVIDIA_PROVIDER_SETUP.md` | دليل إعداد مزودات NVIDIA بعد نقل مفاتيحها من الكود |
| `tests/maro-natural-ai.test.mjs` | اختبار بحث الملفات وفحص الصياغة وصورة الملف والمنشن الانتقائي وتحليل الذاكرة |
| `tests/ai-provider-smoke.test.mjs` | اختبار حي محدود لمزودات Gemini وClaude وGPT وQwen وDeepSeek |
| `src/handler.js` | إصلاح تعريف محدد معدل مكرر كان يمنع تحميل الملف |

## التحقق المنفذ

اجتازت 132 وحدة AI داخل `src/scraper` و`plugins/ai` فحص الصياغة. ونجح الاختبار النصي الحي للمزودات Gemini وClaude وGPT وDeepSeek؛ أما Qwen فأعاد استجابة لكن بمعرف نموذج مختلف عن المطلوب، لذلك لم يُضف إلى المسار التلقائي. كما نجحت اختبارات النوايا الطبيعية والمراجعة الوحدوية ودورة التعديل والموافقة واختبار مزود Manus المحاكى. ونجح فحص الصياغة الشامل لـ1027 ملف JavaScript/ESM/CJS في المشروع خارج بيانات التشغيل المحلية. لم يُنفذ طلب حي إلى Manus لأن المفتاح الخاص بالمالك لم يُضف إلى بيئة هذا الاختبار.

## الأرشيفات المرفقة

يتوفر أرشيفان. أرشيف المصدر النظيف يستبعد بيانات التشغيل المحلية والاعتماديات الضخمة. أما أرشيف النقل الكامل فيتضمن الكود و`config.js` والجلسات وقاعدة البيانات والنسخ الاحتياطية، ويستثني `node_modules` فقط لأنها قابلة لإعادة التثبيت بالأمر `npm install` بعد فك الضغط.

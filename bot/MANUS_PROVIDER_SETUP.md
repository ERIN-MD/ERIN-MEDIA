# تفعيل مزود Manus في Tarboo Bot

## ما الذي تمت إضافته؟

أضيف المزود الاختياري `src/scraper/manus-agent.js` إلى نظام مراجعة الكود المتعدد النماذج. عند توفر مفتاح Manus صالح، يُضاف **Manus** تلقائياً كمحلل إضافي إلى تقارير `حلل ملف:` و`راجع ملف:`. يبقى Gemini وClaude Haiku وGPT كما هم، ولا يتعطل أي منهم إذا كان مزود Manus غير مهيأ أو تعذر اتصاله.

> هذا التكامل يستخدم API المهام العام لـ Manus، وليس أسرار بيئة لوحة التحكم أو مفاتيح البيئة الداخلية الخاصة بالتطوير.

## التفعيل

أنشئ مفتاح API خاصاً بك من حساب Manus المناسب لاستخدام API، ثم خزّنه في متغير بيئة على السيرفر الذي يعمل عليه البوت. لا ترسل المفتاح عبر واتساب أو في المحادثة، ولا تضفه إلى `config.js`، ولا تحفظه داخل مستودع Git.

```bash
export MANUS_API_KEY='ضع-مفتاحك-هنا'
npm start
```

في Pterodactyl أو أي لوحة استضافة، أضف المتغير بالاسم نفسه في قسم **Startup Variables / Environment Variables** ثم أعد تشغيل البوت. لا يلزم أي تعديل آخر في الكود. وللاختبارات المحلية فقط، يمكن تعيين `MANUS_API_BASE_URL` إلى عنوان بديل؛ لا تستخدمه في الإنتاج ما لم يكن عنوان API معتمداً لديك.

| المتغير | مطلوب | الغرض |
|---|---:|---|
| `MANUS_API_KEY` | نعم لتشغيل Manus | مفتاح API الخاص بك، يقرأه السيرفر فقط. |
| `MANUS_API_BASE_URL` | لا | بديل لعنوان API عند الاختبار. العنوان الافتراضي هو `https://api.manus.ai`. |

## السلوك الآمن

عند التحليل، ينشئ Tarboo Bot مهمة خاصة غير تفاعلية ويطلب تقريراً عربياً فقط. يضبط التكامل الخصوصية على `private`، ولا يوافق تلقائياً على أي إجراء، ولا يرسل أوامر نظام، ولا يفتح روابط أو يشغّل موصلات بطلب من نص الملف. إذا أصبحت المهمة في حالة انتظار، يتوقف التقرير ويبلغ عن الحالة بدلاً من تأكيد أي طلب خارجي.

تعمل مهام Manus بصورة غير متزامنة؛ لذلك ينتظر المزود مدة محدودة للحصول على التقرير، ثم يفشل بأمان عند انقضاء المهلة. تعتمد آلية الإنشاء والاستعلام على واجهتي [`task.create`](https://open.manus.ai/docs/v2/task.create) و[`task.listMessages`](https://open.manus.ai/docs/v2/task.listMessages)، وتتعامل مع حالات `running` و`stopped` و`waiting` و`error` كما هو موثق في [دورة المهمة](https://open.manus.ai/docs/v2/task-lifecycle).

## التحقق

نفّذ الاختبار المحاكى الآتي بعد النقل إلى خادمك:

```bash
node tests/manus-agent.test.mjs
```

بعد إضافة المتغير وإعادة تشغيل البوت، استخدم داخل مجموعة مفعّل فيها Auto AI ومع منشن للبوت أو رداً عليه:

```text
حلل ملف: src/handler.js
```

يفترض أن يظهر قسم جديد بعنوان `Manus:` ضمن *تقارير النماذج*. إن لم يظهر، راجع سجل تشغيل البوت؛ سيظل التقرير صادراً من المزودات الأخرى ولن تُطبّق أي تعديلات تلقائياً من دون موافقة المالك الصريحة.

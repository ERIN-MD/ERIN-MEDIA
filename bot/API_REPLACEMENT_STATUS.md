# حالة استبدال مصادر API في Tarboo Bot

> أُنجز هذا التحديث من دون إضافة Alkitab، ومن دون حفظ أي مفتاح API أو Bearer token في ملفات `src/` أو `plugins/`.

|---|---|---|---|---|

| `TikWM` / بحث TikTok القديم | `src/scraper/tiktoksearch.js`، بلوقن TikTok | محول للهيكل الجديد وYuuLabs للتنزيل | اختبار محول الاستجابة ناجح | يعمل مع متغيرات TikTok الاختيارية |

## إعدادات البيئة المطلوبة

| المتغير | الغرض | مطلوب للتشغيل؟ | ملاحظة |
|---|---|---:|---|
| `SPOTIFY_DL_API_TOKEN` | اعتماد مزود تحويل Spotify | نعم، لأمر Spotify فقط | لا يوضع داخل الكود أو الأرشيف. |
| `SPOTIFY_DL_META_URL` | تغيير endpoint بيانات Spotify | لا | الافتراضي هو مزود dlapi الحالي. |
| `SPOTIFY_DL_CONVERT_URL` | تغيير endpoint التحويل | لا | يستخدم عند تبدل مسار المزود. |
| `SPOTIFY_DL_TASK_URL` | تغيير endpoint الاستعلام عن المهمة | لا | يستخدم مع مهمات التحويل الطويلة. |
| `TIKTOK_SEARCH_API_URL` | تغيير endpoint بحث TikTok | لا | يحافظ على مرونة المصدر عند تغيره. |
| `TIKTOK_SEARCH_API_KEY` | اعتماد بحث TikTok إن طلبه المصدر | لا | لا يخزن في ملفات المشروع. |

## حدود مهمة

يظل فحص الشبكة مؤشراً تقنياً وليس ضماناً دائماً؛ يمكن أن تتبدل شروط المواقع ومحددات السرعة أو بنيات النتائج دون إنذار. تم اختبار نقاط النهاية ذات الأولوية بقراءات محدودة فقط، ولم يُشغّل أي تنزيل مستخدم أو تحويل مدفوع أو طلب يتضمن بيانات شخصية. مزود Spotify لا يمكن اختباره حياً قبل ضبط `SPOTIFY_DL_API_TOKEN` في بيئة HidenCloud.

بطاقات المطور والمكالمة المحلية تستعمل الصورة المرفقة أو صورة الملف الشخصي عند توافرها، وتضمّنها داخل التصميم محلياً من دون رفعها إلى أي خدمة خارجية. بطاقات الألعاب والمطور والمكالمة تحمل وصف **تصميم ترفيهي/غير رسمي** حتى لا تُفهم كسجلات أو واجهات أصلية.

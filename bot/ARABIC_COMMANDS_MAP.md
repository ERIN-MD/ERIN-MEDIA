# خريطة تعريب أوامر وملفات Tarboo Bot

هذا التقرير يصف طبقة التعريب الحالية من دون تغيير مفاتيح قاعدة البيانات أو أسماء الحقول البرمجية الحساسة. يظل اسم الملف الداخلي مقبولاً عندما تكون إعادة تسميته قد تكسر استيرادات قديمة؛ أما اسم الأمر الظاهر للمستخدم والردود فيجب أن يكونا عربيين قدر الإمكان.

| المجال | الأمر أو المسار العربي المعتمد | الوحدة ذات الصلة | ملاحظة التوافق |
|---|---|---|---|
| الذكاء الاصطناعي | `autoai`، `حالة`، طلبات طبيعية | `plugins/group/autoai.js`، `src/lib/maro-auto-ai.js` | يدعم غياب `alwaysReply` في الإعدادات القديمة. |
| حماية الروابط | `منع_روابط الكل` و`منع_روابط واتس` | `src/lib/maro-link-guard.js` | تُجمع السياسات في حارس واحد مع بقاء الأوامر القديمة متوافقة. |
| التشخيص | `أخطاء البلوقنات` و`أصلح استيرادات البلوقنات` | `src/lib/maro-plugin-diagnostics.js` | يقتصر الإصلاح على الاستيرادات الآمنة مع نسخة احتياطية. |
| AI Studio | `حلل هذا الملف` و`أنشئ بلوقن` و`حسن هذه الصورة` | `src/lib/maro-ai-studio.js` | التعديل أو التوليد الخارجي يحتاج موافقة المالك. |
| المجموعة | أسماء عربية داخل `plugins/group/` | بلوقنات المجموعة | تُحفظ أسماء JavaScript اللازمة للتوافق عند وجود استيراد قديم. |
| الألعاب والبيانات | نصوص رد عربية ومفاتيح داخلية ثابتة | `database/` وبلوقنات اللعبة | لا تُترجم المفاتيح أو المعرفات المخزنة لتفادي فقدان البيانات. |

## قواعد إعادة التسمية الآمنة

لا يُعاد تسمية وحدة في `src/lib` مباشرةً إذا كانت مستخدمة في استيرادات قائمة. يُنشأ بدلاً من ذلك ملف توافق يعيد تصدير الواجهة القديمة، ثم تُحدّث الاستيرادات تدريجياً بعد فحص الصياغة. ولا تُترجم مفاتيح JSON أو جداول قاعدة البيانات أو متغيرات البيئة؛ لأنّها عقود تشغيلية وليست نصوص واجهة.

> يستخدم هذا التقرير مرجعاً للتعريب المستقبلي، ولا يغير أي إعداد أو بيانات تشغيلية بمفرده.

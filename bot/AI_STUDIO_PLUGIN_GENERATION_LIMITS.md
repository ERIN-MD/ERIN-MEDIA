# حدود توليد البلوقنات في Tarboo Bot AI Studio

يتعامل AI Studio مع طلب «أنشئ بلوقن» على أنه **مسودة قابلة للمراجعة**، لا كتنفيذ تلقائي. يستخرج الاسم والفئة التقريبية من الطلب، ويحدد ما إذا كان البلوقن يحتاج نصاً، ويدعم أنماطاً نصية بسيطة مثل الترحيب، رسالة الحالة، أو إعادة النص. ثم يفحص JavaScript قبل عرض المعاينة.

لا يقبل الحارس الأمني المسودات التي تشمل تنفيذ أوامر نظام، أو `eval`، أو دوال ديناميكية، أو حذف ملفات، أو قراءة متغيرات البيئة، أو طلبات شبكة تغير البيانات. لا يضيف البوت أي ملف قبل أن يكتب المالك: `وافق على البلوقن PLUG-...`.

عند استيراد بلوقن خارجي، يحتفظ النظام بالنسخة الأصلية في `backup/ai-studio-imports/`، ويكيّف اسم البلوقن وفئته إلى بنية Tarboo Bot، ثم يعرض فرقاً نصياً قبل الموافقة. البلوقنات المعقدة أو التي تحتاج قواعد بيانات أو مفاتيح API أو شبكة أو صلاحيات حساسة تتطلب مراجعة يدوية بدلاً من توليد تلقائي.

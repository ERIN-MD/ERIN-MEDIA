# حدود الأمان في Tarboo Bot AI Studio

يحوّل AI Studio الطلبات الطبيعية إلى خطط قابلة للمراجعة، وليس إلى تنفيذ غير محدود. هذا الفصل ضروري لأن البوت سيتعامل مع ملفات المستخدمين وبلوقنات خارجية وعمليات إنشاء صور وملفات.

## مستويات الصلاحية

| المستوى | أمثلة | السلوك |
|---|---|---|
| قراءة عامة | شرح بلوقن مرفق، تلخيص مستند نصي، إرسال صورة الحساب | قراءة أو إرسال فقط، مع احترام خصوصية واتساب. |
| إجراءات مجموعة | منشن المشرفين أو الأعضاء، بطاقات وأزرار ورسائل Meta | للمشرف أو المالك فقط، وتخضع لحدود منع الإزعاج. |
| فحص مشروع | بحث ملف، تحليل أخطاء، تحليل الذاكرة، مراجعة بلوقن | للمالك فقط، قراءة فقط، ولا يفتح الجلسات أو قواعد البيانات أو الأسرار. |
| إنشاء أو تعديل كود | إنشاء بلوقن، تكييف بلوقن خارجي، دمج بلوقنات | للمالك فقط، مع معاينة فرق، موافقة صريحة، نسخة احتياطية، وفحص صياغة واستيرادات. |
| طلبات خارجية مدفوعة أو بطيئة | إنشاء/تعديل صور، مزود Manus، خدمات API اختيارية | للمالك فقط عند الحاجة، مع إظهار المزود وعدم تخزين المفاتيح في الكود. |

## قواعد الملفات المرفقة

تُعامل الملفات المرسلة أو المعاد توجيهها كبيانات غير موثوقة. يمكن قراءة النصوص والكود والـJSON وMarkdown وملفات الإعدادات المسموح بها ضمن حجم محدود. لا يجري AI Studio استيراد الملف أو تشغيله أو فك أرشيفه أو تنفيذ أي أمر داخله. الملفات الثنائية والمستندات التي تحتاج استخراجاً خاصاً تُعرض كطلب منفصل للقراءة فقط ولا تصبح كوداً قابلاً للتنفيذ.

## قواعد إنشاء البلوقنات

يتلقى AI Studio وصفاً طبيعياً مثل «أنشئ بلوقن يحول MP3 إلى رسالة صوتية». ينشئ خطة وملفاً مقترحاً داخل الفئة المطلوبة، لكن لا يكتب الملف النهائي قبل موافقة المالك. يجب أن يلتزم البلوقن بعقد `config` و`handler` الموجودين في `maro-plugins.js`، وباسم أمر عربي قصير وفئة واضحة، ثم يجتاز فحص JavaScript قبل اعتماده.

## قواعد الوسائط وواجهة واتساب

يدعم AI Studio إرسال نصوص وملفات وصور وصوت وأزرار وبطاقات وواجهات Meta عبر الطبقات الموجودة في البوت. لا يرسل رسالة جماعية أو منشن واسع أو ملفاً خارج المحادثة المطلوبة من دون تحقق من الصلاحية والحجم. تختار طلبات الصور مزوداً من المسارات المتاحة وتبقى منفصلة عن أوامر تعديل الكود.

## التعريب والدمج

لا يُعاد تسمية مئات الملفات دفعة واحدة. تتم الترجمة عبر `config.name` و`alias` أولاً مع الحفاظ على aliases القديمة للتوافق، ثم يدمج كل زوج أو مجموعة من البلوقنات المتشابهة في ملف واحد بعد اختبار مستقل. أول مرشح هو أدوات منع الروابط المتعددة، لكن لن يُدمج أي ملف قبل جرد أوامره وخياراته وقواعده الحالية.

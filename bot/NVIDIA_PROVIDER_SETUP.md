# إعداد مزودات NVIDIA الاختيارية

أزيلت مفاتيح NVIDIA من بلوقنات `ديب_برو4` و`زد_اي` و`نيمو_نانو` و`نيموترون`. لا تعمل هذه البلوقنات الآن إلا بعد تخزين مفتاح جديد خاص بك في بيئة الاستضافة، لا في `config.js` ولا في أي ملف للمشروع.

```bash
# مفتاح واحد
NVIDIA_API_KEY=ضع_مفتاحك_هنا

# أو أكثر من مفتاح للتبديل عند تعذر أحدها
NVIDIA_API_KEYS=مفتاح_اول,مفتاح_ثان
```

ضع المتغير في لوحة الاستضافة ثم أعد تشغيل البوت. لا ترسل المفتاح في واتساب أو داخل المحادثة. إن كانت المفاتيح القديمة قد استُخدمت أو نُشرت، ألغها أو دوّرها من لوحة مزودها قبل أي استخدام جديد.

> لا تستخدم هذه البلوقنات تلقائياً داخل Auto AI. تبقى أوامر يدوية منفصلة بعد إعدادك الصريح للمفتاح.
